# Turso / libSQL database notes\n\n- The live database is remote and configured with `TURSO_DATABASE_URL` and `TURSO_AUTH_TOKEN`.\n- The schema is initialized from `database/schema.sql` at application startup.\n- Repository functions are asynchronous; callers must `await` them.\n- Do not place a live SQLite file on Render Free: its filesystem is ephemeral.\n- Import existing data with `migration/import-sqlite-to-turso.js`.\n
